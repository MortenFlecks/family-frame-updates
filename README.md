# Family Frame downloads

Download the latest Android installer from [Releases](https://github.com/MortenFlecks/family-frame-updates/releases/latest). Android 8.0 or newer, including Android 12.

This repository contains installers, release notes and latest.json update metadata only. No photos, album links, accounts or signing keys are stored here.

The app checks daily while open. Tap App updates, then confirm installation in Android. Updates keep your settings and cached photos.

The first permanently signed release requires uninstalling the older prototype because its original signing key was lost. That one-time reinstall resets local settings and cache. Google Photos originals are unaffected.
